# Comprehensive Evaluation of Hardcoded Values in EquiSight Alpha

This document provides a systematic audit of all hardcoded values, constants, fallbacks, and heuristics identified across the **EquiSight Alpha** codebase (`pipeline/` and `src/`). 

Each hardcoded value is categorized and evaluated with an explicit determination:
- **`Misleading`**: Values that fabricate, synthesize, or distort financial facts, historical performance, macroeconomic indicators, options metrics, or platform authorship, presenting artificial data to users or models as if it were real, measured market data.
- **`Not Misleading`**: Legitimate engineering constants, statutory regulatory thresholds (e.g., SEC Rule 3a51-1), documented academic/capital market assumptions (e.g., Damodaran multiples, statutory tax rate), documented quantitative framework bounds, or UI layout parameters.
