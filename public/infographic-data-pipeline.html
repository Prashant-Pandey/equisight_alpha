3 Deep Dive: Multi-Source Scraper Architecture (6 Concurrent Sub-Pipelines)

The Web & Financial Intelligence Scraper operates under a 100% free, zero-paid API architecture requiring 0 accounts or billing keys. In pipeline/src/ingestion/webScraper.ts, the orchestrator triggers WebScraper.scrapeStockIntelligence(), which fires 6 concurrent asynchronous fetch promises via Promise.allSettled(). Failure in any single scraper stream degrades gracefully with honest zero-synthesis fallback without blocking the pipeline.

Stream 01 • Corporate Catalysts
Google News RSS Engine
Free RSS XML
GET news.google.com/rss/search?q=${encode(query)}&hl=en-US
  • Query Formulation: Constructs targeted search string: `${companyName} ${ticker} stock` (or fallback `${ticker} stock`).
  • XML Sanitization: Regular expression parsing on RSS `<item>` nodes; strips CDATA wrappers and decodes HTML entities (`&quot;`, `&amp;`, `&#39;`).
  • Ingestion Yield: Harvests top 6 news articles with publisher source, publication timestamp, and canonical link.
  • Theme Extraction: Automatically classifies catalysts into 5 major buckets: Financial Disclosures, Wall Street Revisions, Capital Allocation, Biopharma/FDA Catalysts, and Capital Structure Dilution.

Public REST API

4 Two-Tiered News Catalyst & Sentiment Pipeline (Tier 1 Fast Extraction & Divergence Detection)

To eliminate the "Good News = Green / Bad News = Red" naive assumption and protect against RSS spam, the architecture executes a decoupled, two-tiered synthesis pipeline. Tier 1 performs rapid headline filtering, entity relevance scoring, and expectation divergence detection in socialSentiment.ts, pre-structuring intelligence for the Tier 2 institutional valuation agent in synthesisAgent.ts.

Tier 1: Fast Catalyst Extraction & Filtering

Tier 1 • Ingestion Phase
Engine: gemini-3.6-flash-low
Target Latency: < 2.5s
Timeout Guard: 15,000ms
Output: Strict JSON Schema
  • Entity Relevance Gate (0–10): Rejects low-relevance clickbait and listicles (e.g. "Top 10 Stocks to Buy Before March" scores 2/10 and is dropped; 10-K filing or earnings beats score 9–10/10). Minimum passing threshold: relevanceScore >= 6.
  • 13-Class Catalyst Taxonomy: Classifies headlines into EARNINGS, GUIDANCE, FDA_APPROVAL, M_AND_A, CONTRACT_WIN, OFFERING_DILUTION, MACRO_REGULATORY, etc.
  • Expectation Gap Detection: Cross-references net catalyst sentiment against real-time session price velocity (changePercent) to compute catalystAlignment.
  • Deterministic 15s Fallback: If `agy` CLI fails or exceeds 15 seconds, a deterministic keyword regex engine extracts headlines, scores relevance via regex density, and categorizes catalysts without pipeline blocking.

● Bullish & Bearish Sentiment Calculation
pipeline/src/ingestion/socialSentiment.ts
identified = stockTwits.bullishCount + stockTwits.bearishCount
bullishPercent = (stockTwits.bullishCount / identified) × 100
bearishPercent = 100 - bullishPercent
sentimentScore = (stockTwits.bullishCount - stockTwits.bearishCount) / identified
  • bullishPercent: Percentage of sentiment-tagged messages classified as bullish. Formatted as `parseFloat(bullishPercent.toFixed(1))`.
  • bearishPercent: Complementary bearish share (`100 - bullishPercent`).
  • sentimentScore: Normalized scalar bounded within `[-1.0, +1.0]`. Where `+1.0` = 100% Bullish, `-1.0` = 100% Bearish.
  • Zero-Data Policy: If `totalSources === 0`, returns `bullishPercent: 0` and `sentimentScore: 0` (Strict zero-synthesis honesty policy). If messages exist but none are tagged, defaults to neutral baseline `50.0%`.
// Extracted from SocialSentimentIngestor.getSentiment() const identified = stockTwits.bullishCount + stockTwits.bearishCount; let bullishPercent: number, score: number; if (identified > 0) { bullishPercent = (stockTwits.bullishCount / identified) * 100; score = (stockTwits.bullishCount - stockTwits.bearishCount) / identified; } else { bullishPercent = 50.0; // Neutral baseline when untagged score = 0.0; }

● Option Gamma Imbalance & Dealer Short-Gamma Formulation
Black-Scholes Γ Skew
d₁ = [ ln(S / K) + (r + 0.5 σ²) T ] / [ σ √T ]
Γ = e^(-0.5 d₁²) / [ √(2π) × S × σ × √T ]
Total Call Γ = ∑ (Γᵢ × OIᵢ × 100)  |  Total Put Γ = ∑ (Γⱼ × OIⱼ × 100)
imbalanceRatio = Total Call Γ / Total Put Γ
  • Spot Price (S): Live regular session equity price from quote or options contract chain metadata.
  • Implied Vol (σ): Contract-specific IV from listed options chain (calibrated fallback: 0.45). Risk-free rate `r = 0.045`.
  • Expiry Horizon (T): Annualized time to expiry `max(1/365, (exp - now) / 31,536,000)`.
  • imbalanceRatio: Open-interest weighted Call-to-Put gamma multiplier. Evaluates market-maker hedging vulnerability.
Gamma Ratio Risk Tier Dealer Exposure Profile
≥ 3.0x Severe Dealer Short Gamma: Reflexive upside delta-hedging squeeze
≥ 1.8x High Asymmetric Upside Skew: Elevated vulnerability on momentum
≥ 1.25x Moderate Moderate Call Gamma Skew: Bullish speculation without systemic squeeze
0.7x – 1.25x Low Balanced Gamma Distribution: Orderly two-way order book flow
≤ 0.7x Low Dealer Long Gamma / Put Skew: Protective put buffer dampens volatility
None / Empty Low No Listed Options Chain: Equity exempt from derivative squeeze mechanics
● Free Float Concentration & Turnover Velocity
Supply-Side Illiquidity Auditor
freeFloatShares = sharesOutstanding × (1 - heldPercentInsiders)
freeFloatPercent = (freeFloatShares / sharesOutstanding) × 100
floatTurnoverRatio = sessionVolume / freeFloatShares
  • freeFloatPercent: Percentage of total capitalization freely floating in public secondary circulation.
  • floatTurnoverRatio: Proportion of tradable float exchanging hands in a single trading session.
  • Cornering Hazard: Ultra-tight float (≤10%) combined with high turnover (≥70%) creates immediate artificial liquidity vacuums.
Concentration Tier Trigger Condition Market Structural Vulnerability
Extreme Float ≤ 10% OR Turnover ≥ 70% High vulnerability to cornering, pump-and-dump mechanics & supply vacuums
High Float ≤ 20% OR Turnover ≥ 30% Constrained tradable float; order imbalances trigger magnified swings
Moderate Float ≤ 45% OR Turnover ≥ 15% Standard capitalization; adequate secondary liquidity buffer
Low Float > 45%, Turnover < 15% Liquid float; broad institutional distribution insulates from artificial squeezes
